## `> how.we.build`

<img src="./assets/systems.svg" width="100%" alt="Подход Bakunity к созданию систем" />

```text
проблема → продукт → инфраструктура → автоматизация → эксплуатация → улучшение
```

Bakunity строит не набор отдельных технологий, а целую рабочую систему:
от продукта и backend до инфраструктуры, сетей, автоматизации и эксплуатации.


## `> public`

- **[Bakunity RDP](https://github.com/Bakunity/RDP)** — открытое направление удалённого доступа.
- **[Bak VPN](https://bakvpn.me)** — сетевой продукт Bakunity.
- **[TimaBak](https://github.com/TimaBak)** — профиль основателя и публичные эксперименты.

Большая часть внутренней инфраструктуры и продуктовой разработки остаётся в приватных репозиториях.

## `> principles`

```text
01  продукт должен решать реальную задачу

04  безопасность проектируется заранее
05  запуск → эксплуатация → данные → улучшение
```
